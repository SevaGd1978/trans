# Магистраль

Веб-приложение для бюджета транспортно-экспедиторской компании: сводный отчёт 1С по заказам, статьи «сумма / исполнителю / диспетчеру», маршруты, ГСМ, план-факт.

Демо-данные — ООО «СеверТранс», бюджет 2026 года. Рабочие цифры берутся из файла 1С «Сводный отчет по выбранным заказам» (CSV Windows-1251 или Excel).

## Возможности

- Сводка: выручка, затраты, прибыль и блок заказов 1С (сумма, исполнители, диспетчеры)
- Годовой бюджет по статьям, включая оплату исполнителям и диспетчерам
- Журнал доходов и расходов: импорт CSV/Excel сводного отчёта 1С
- Импорт заправок Excel: дата, госномер, одометр, литры, цена, сумма
- Карточки ТС, маршруты из загрузки/разгрузки, маржа заказа
- План-факт и сценарии (объём заказов масштабирует оплату перевозчикам)
- Данные хранятся в браузере; очистка и учебные записи закрыты паролем

## Запуск

```bash
npm install
npm run dev
```

Сборка и проверка:

```bash
npm test
npm run build
npm run preview
```

Откройте http://localhost:5173
