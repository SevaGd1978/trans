# Магистраль

Веб-приложение для планирования бюджета транспортной компании: автопарк, маршруты, статьи ГСМ и ФОТ, план-факт и сценарный пересчёт.

Демо-данные — ООО «СеверТранс», бюджет 2026 года, факт по сентябрь.

## Возможности

- Сводка: выручка, затраты, прибыль, структура расходов, состояние парка
- Годовой бюджет по статьям и месяцам, автозаполнение ГСМ из пробега и расхода
- Журнал доходов и расходов с привязкой к машине
- Карточки ТС: лизинг, страховка, плановый пробег, ₽/км
- Маршруты: топливо на рейс и маржа
- План-факт с отклонением по статьям
- Сценарии: цена дизеля, объём, зарплаты, ремонт
- Данные хранятся в браузере, демо можно сбросить

## Запуск

```bash
npm install
npm run dev
```

Сборка и проверка:

```bash
npm test
npm run build
npm run preview
```

Откройте http://localhost:5173
